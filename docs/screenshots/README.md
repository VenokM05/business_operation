# Screenshots

Place PNG captures of the running application here and reference them from the
**Screenshots** section of the root `README.md`.

## How to capture

1. Start the app: `php artisan serve` (and `npm run build` or `npm run dev` for assets).
2. Sign in with a demo account (see the README — e.g. `admin@boms.test` / `password`).
3. Capture each screen at desktop width (~1440px) and save with the names below.

| File | Screen |
| --- | --- |
| `01-login.png` | `/login` |
| `02-dashboard.png` | `/dashboard` |
| `03-clients.png` | `/clients` |
| `04-client-detail.png` | `/clients/{id}` |
| `05-project.png` | `/projects/{id}` |
| `06-service-request.png` | `/service-requests/{id}` |
| `07-request-timeline.png` | Request detail, activity timeline |
| `08-reports.png` | `/reports` |
| `09-activity-logs.png` | `/activity-logs` |

> Use only the fake, local demo data from `php artisan db:seed` — never capture real customer data.
